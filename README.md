# Business-Intelligence-UTS
# Business Intelligence Project - Sample Superstore

## Deskripsi Project
Project ini merupakan implementasi Business Intelligence menggunakan dataset Sample Superstore. Project meliputi proses ETL (Extract, Transform, Load), pembangunan data warehouse menggunakan star schema, serta visualisasi dan analisis data penjualan retail.

## Dataset
Dataset yang digunakan pada project ini adalah Sample Superstore Dataset yang diperoleh dari Kaggle.

## Tools yang Digunakan
- Google Colab
- Python
- Pandas
- Tableau / Power BI
- GitHub

## File Project
- `BI_Project.ipynb` → Notebook proses ETL dan analisis data
- `superstore_clean.csv` → Dataset hasil cleaning dan transformasi
- `laporan.pdf` → Laporan project Business Intelligence

## Proses Project
1. Extract data dari file CSV
2. Transformasi dan cleaning data
3. Load dataset hasil transformasi
4. Pembuatan data warehouse dengan star schema
5. Visualisasi dan analisis data

## Hasil Analisis
Beberapa insight yang diperoleh dari hasil analisis data:
- Kategori Technology memiliki total penjualan tertinggi
- Region West memiliki profit terbesar
- Diskon yang terlalu besar dapat menurunkan profit
- Penjualan dan profit meningkat dari tahun ke tahun

## Kesimpulan
Penerapan Business Intelligence pada dataset Sample Superstore membantu proses analisis data menjadi lebih terstruktur sehingga mempermudah pengambilan keputusan bisnis berdasarkan data penjualan dan profit perusahaan.
